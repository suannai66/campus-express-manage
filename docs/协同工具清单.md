## 2. 统计口径

- 统计截至 2026 年 11 月 10 日，依据 GitHub PR 记录与 main 提交历史。
- “main 可达提交”包含合并提交及其引入的功能分支提交；“第一父链提交”单独计算主线沿第一父提交回溯的记录，两者不可相加。
- 文档变更数按团队接口约定、任务清单和协同工具清单三个路径的非合并提交去重计数，包含首次建立；同一提交修改多份文档只计一次。PR 统计包含全部记录，关闭未合并的 PR 不计入合并数。
- 代码托管与文档协作均使用 GitHub。
- Git 命令调用次数、测试累计执行次数没有统一日志，不能用提交数或测试用例数替代。
